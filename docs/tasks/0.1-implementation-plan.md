> **Mapping:** `project-context.md §11 Phase 1`

---

## 1. Context

`capigo-api-sdk` is currently a greenfield repo: only `docs/project-context.md` (spec v2.1) + `api/openapi.json` (OpenAPI 3.0.3 of Capigo Public API v1) + boilerplate files (LICENSE, README, CHANGELOG, CONTRIBUTING, CODE_OF_CONDUCT, SECURITY). No Go source exists yet.

Milestone **0.1** = the entirety of Phase 1 MVP per `project-context.md §11`: scaffold the Go project, build a single-binary CLI `capigo` wrapping the Capigo Public API at `/api/v1/*`, sufficient for internal dev team dogfooding. Includes CI/CD + GoReleaser from day one so every merge to `main` can produce a releasable binary.

## 3. File-by-file plan

### Root
- `go.mod` — module `github.com/vtech-com/capigo-api-sdk`, Go 1.22
- `main.go` — entrypoint, calls `cmd.Execute()`. Declares `version`, `commit`, `date` variables for ldflags injection.
- `Makefile` — `build`, `test`, `lint`, `release-snapshot`, `install`
- `.goreleaser.yml` — per template §8.4
- `.golangci.yml` — enables `gofmt`, `govet`, `errcheck`, `staticcheck`, `gosec`
- `.gitignore` — `dist/`, `*.local`, `.capigo/`, `*.env`, coverage files

### `cmd/` (Cobra command tree, one file per noun)
- `root.go` — root cmd `capigo`, persistent flags, `cobra.OnInitialize` to load config + bind viper env vars (`CAPIGO_API_KEY`, `CAPIGO_TENANT`, `CAPIGO_PROFILE`, `CAPIGO_API_URL`)
- `auth.go` — `auth login --key csk_...`, `auth logout`, `auth whoami` (calls `GET /me`)
- `config.go` — `config set <k> <v>`, `config get <k>`, `config set-default-tenant <code>`, `config unset-default-tenant`
- `tenants.go` — `tenants list` (`GET /tenants`)
- `tasks.go` — `tasks list` (`GET /mission/tasks` with `--status`, `--parent-task-id`, `--page`, `--limit`), `tasks get <id>`, `tasks create --title --description --priority --status --due-date --assignee --board --list`
- `boards.go` — `boards list` (`GET /mission/boards`)
- `version.go` — print version/commit/date

### `internal/api/`
> **Note:** `internal/` is a Go convention — packages inside `internal/` can only be imported by code in the same module. This is unrelated to the "Capigo internal API" (`/api/internal/*`) on the server — the CLI only calls `/api/v1/*`.

- `client.go` — `type Client struct { http *http.Client; baseURL, apiKey string }`. Method `Do(ctx, method, path, body, tenant *string) (*Response, error)` injects `Authorization`, `X-Tenant-Code` (only when `tenant != nil`), `User-Agent: capigo-api-sdk/<v> (<os>; <arch>)`, `X-Request-Id` (uuid). HTTPS-only; rejects `http://` unless localhost.
- `errors.go` — `APIError{Code, Message, RequestID, HTTPStatus}`. Function `ExitCodeFor(err) int` maps per §4.4: `0` success / `1` general / `2` auth (401) / `3` permission (403) / `4` not found (404) / `5` validation (400) / `6` network / `7` rate limit (429).
- `tenant.go` — `ResolveTenant(flag *string, noTenant bool, env, defaultTenant string) (tenant *string, isGlobal bool)` per precedence §3.4. Per-endpoint rules: `PCMSRequiresTenant`, `CreateTaskUsesBodyField` so `cmd/` does not hard-code this logic.
- `models.go` — Go structs matching OpenAPI: `Tenant`, `Member`, `Board`, `BoardDetail`, `Task`, `Product`, `ProductVariant`, `CreateTaskRequest`, `Meta`, `Envelope[T]` (`Data`, `Meta`). Hand-generated (Phase 1, ~9 endpoints) — `oapi-codegen` not needed yet.
- `paginate.go` — `FetchAll[T](ctx, client, path, params) ([]T, error)` iterates pages until `has_more=false`. (Phase 1 does not expose `--all` in the CLI, but the helper is ready for future use.)

### `internal/config/`
- `store.go` — Load/Save `~/.capigo/config.json`, atomic write (`*.tmp` then `os.Rename`) + `chmod 0600`, schema v1 per §3.3. Functions `ActiveProfile()`, `SetProfile(name)`, `MergeKnownTenants([]string)`.
- Post-write check: verify file permissions = `0600`, fail loudly if not.

### `internal/output/`
- `formatter.go` — `Render(w io.Writer, mode string, data any, opts RenderOpts)`. Table uses `github.com/jedib0t/go-pretty/v6/table`. Dynamic Tenant column: when `opts.GlobalMode==true` inserts a `Tenant` column. JSON: `json.MarshalIndent`. Quiet: prints ID or primary key.
- `resourceRenderers` map registers columns + ID extractor per resource type.

### `internal/version/`
- `version.go` — variables `Version`, `Commit`, `Date` (set by ldflags), helper `UserAgent()` returns `capigo-api-sdk/<v> (<os>; <arch>)`.

### `pkg/`
> Go convention for code intended for external import as a library. Phase 1 **left empty** — code will be lifted from `internal/` once the API stabilizes and a Go SDK library release is desired (post-v1.0).

### `.github/`
- `workflows/ci.yml` — matrix Linux/macOS/Windows × Go 1.22; runs `go test ./...`, `golangci-lint`, `govulncheck`
- `workflows/release.yml` — triggers on tag `v*`, runs `goreleaser release --clean`
- `workflows/codeql.yml` — CodeQL for Go
- `dependabot.yml` — gomod weekly, github-actions weekly
- `ISSUE_TEMPLATE/bug_report.md`, `feature_request.md`
- `PULL_REQUEST_TEMPLATE.md`
- `CODEOWNERS` — `* @luutronghieu` (placeholder)

## 4. Key implementation rules (derived from spec)

1. **Tenant precedence** (§3.4): `--tenant` > `--no-tenant` > `$CAPIGO_TENANT` > `config.default_tenant` > global mode. Implement once in `internal/api/tenant.go`, used from the root cmd.
2. **`POST /mission/tasks`**: attach `tenant_code` to the **body**, not the header (OpenAPI §`CreateTaskRequest`). Reject the command if tenant resolution yields global mode. Encode this rule in `internal/api/`, not in `cmd/tasks.go`.
3. **`GET /pcms/products`**: tenant **required** (header) — reject early at the CLI rather than letting the server return 400. No `products` command in 0.1, but the rule must be encoded now for 0.2.
4. **Exit codes**: all `cmd/*` must ultimately call `os.Exit(api.ExitCodeFor(err))`. Never print `error.message` text then exit 1.
5. **Error JSON format** (§4.5): when `--output json` and an error occurs, print `{"error":{"code","message","request_id"}}` to stderr.
6. **No `--api-key` flag** (§10.1 threat model): only accept via env `CAPIGO_API_KEY` or config file. `auth login --key csk_...` is the sole exception (saves to config then clears the flag value from argv to avoid leaking via `ps`).
7. **Redact `Authorization` header** when `--verbose` logs the request.
8. **`User-Agent`** in the exact format per §5.2: `capigo-api-sdk/<version> (<os>; <arch>)`.

## 5. Dependencies

```
github.com/spf13/cobra        v1.8+        CLI framework
github.com/spf13/viper        v1.18+       Config + env binding
github.com/jedib0t/go-pretty  v6           Table renderer
github.com/google/uuid                     X-Request-Id
```

Std lib: `net/http`, `encoding/json`, `os`, `path/filepath`, `runtime`.

Do NOT use an ORM, web framework, or logging framework (`logrus`/`zap`) — std `log` + `--verbose` flag is sufficient.

## 6. Implementation order (suggested)

1. `go.mod`, `main.go`, `cmd/root.go`, `cmd/version.go` — bootstrap to get `capigo version` running

4. `internal/api/models.go` — structs for 9 endpoints matching OpenAPI

7. `cmd/config.go`, `cmd/tenants.go`
8. `cmd/tasks.go` (list/get/create) — exercise tenant rules in all 3 modes

## 7. Verification

- **Local build**: `make build` → produces `./dist/capigo`. `./dist/capigo version` prints version/commit/date correctly.
- **Config flow**: `capigo auth login --key csk_test`, verify `~/.capigo/config.json` permissions = `-rw-------`, JSON matches schema §3.3.
- **Tenant resolution unit test**: table-driven tests covering all 5 branches of §3.4 (`--tenant`, `--no-tenant`, env, default, fallback global).
- **HTTP integration test**: use `httptest.NewTLSServer` to mock `/me`, `/tenants`, `/mission/tasks`, `/mission/tasks/{id}`, `/mission/boards`. Assert `Authorization`, `X-Tenant-Code` (present/absent), `User-Agent`, `X-Request-Id` headers and exit-code mapping for 200/400/401/403/404/429/500.
- **Output**: `capigo tasks list --no-tenant --output json` (mock) — JSON retains `tenant_code`; table mode shows `Tenant` column.
- **Cross-compile**: `goreleaser release --snapshot --clean` produces binaries for linux/darwin/windows × amd64/arm64 + `checksums.txt`.
- **CI**: push branch → matrix green on all 3 OSes.
- **Lint**: `golangci-lint run` + `govulncheck ./...` clean.
- **Smoke against real API** (if key available): `CAPIGO_API_KEY=csk_... capigo tenants list` returns a table of the user's tenants.
