# Code of Conduct

## Our Commitment

We want Capigo CLI SDK to be a welcoming project for everyone. Everyone who participates — whether as a contributor, maintainer, or user — is expected to treat others with respect and professionalism.

## Expected Behavior

- Be kind and patient with other contributors, especially newcomers
- Give constructive feedback focused on the code or idea, not the person
- Accept feedback gracefully
- Respect differing opinions and experiences
- Credit others' work and ideas

## Unacceptable Behavior

- Personal attacks, insults, or derogatory comments
- Harassment of any kind, public or private
- Sharing others' private information without consent
- Sustained disruptive behavior in issues, PRs, or discussions

## Scope

This Code of Conduct applies in all project spaces: GitHub Issues, Pull Requests, Discussions, and any other official communication channel for this project.

## Enforcement

If you witness or experience unacceptable behavior, please email **security@capigo.app** (or open a private report to a maintainer). All reports will be reviewed confidentially.

Maintainers may remove comments, close issues/PRs, or ban accounts that violate this Code of Conduct.
